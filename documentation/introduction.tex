\section{Introduction}
This document outlines the architecture, setup, and execution modules of the Pole Anomaly Project. The overall objective of this project is the dynamic monitoring of radiological pollution using Neural Networks. In the context of continuous environmental surveillance using beacons (e.g., gamma photon counting), the goal is to detect and identify radiological phenomena as soon as they appear. This is achieved through the classification of specific geometric shapes present in highly noisy time-series data.

To accomplish this, the project explores and evaluates different neural network architectures---particularly those utilizing convolutional layers and attention mechanisms---in terms of classification performance, computational cost, and explainability.

A critical component of this machine learning pipeline is the generation of robust training data. Since real-world anomalous radiological events are rare, this repository implements a Stochastic Anomaly Simulator. This data generation module is designed to inject mathematically accurate, user-defined geometrically deformed anomalies (such as Squares, Exponential Curves, and Bell Curves) into synthetic radiation noise based on real-world sensor baselines. The synthetic datasets generated from these anomaly templates will be directly used to train, validate, and test the neural networks for anomaly detection.
