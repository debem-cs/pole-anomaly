\section{CNN+Attention Implementation}

This section walks through the concrete PyTorch implementation of the hybrid CNN + multi-head self-attention network. All paths below are relative to the \texttt{architectures/} directory.

\subsection{Architecture (\texttt{saved\_models/cnn\_attention.py})}

The model has three logical stages:
\begin{enumerate}
    \item A convolutional stem of three Conv-GN-ReLU blocks with stride 2, reducing the temporal length by a factor of $\sim 8$ while widening channels to $(16,32,64)$. The stem extracts \emph{local shape primitives} (peaks, ramps, plateaus).
    \item A standard Transformer encoder (2 layers, 4 heads, 64-dim embedding, GELU, pre-norm) operating on the token sequence produced by the stem. Sinusoidal positional encoding is added before the encoder, and a learnable \texttt{[CLS]} token is prepended to aggregate global context (à la BERT).
    \item A \texttt{LayerNorm} followed by a single linear classifier reading the \texttt{[CLS]} output.
\end{enumerate}

\textbf{Adaptations versus a textbook CNN+Transformer hybrid:}
\begin{itemize}
    \item Stem widened from $(32,64,64)$ to $(16,32,64)$ to keep the heaviest layers compact.
    \item \texttt{GroupNorm(8)} replaces \texttt{BatchNorm1d}: no running statistics, train and eval normalize identically, and the stem becomes amplitude-invariant at inference.
    \item Pre-norm Transformer (\texttt{norm\_first=True}) for stable optimization on small batches.
    \item Last conv layer is exposed as \texttt{self.last\_conv\_features} for Grad-CAM hooks.
\end{itemize}

\begin{lstlisting}[language=Python]
class _ConvStem(nn.Module):
    def __init__(self, in_ch, dims=(16, 32, 64)):
        super().__init__()
        d1, d2, d3 = dims
        self.net = nn.Sequential(
            nn.Conv1d(in_ch, d1, 7, stride=2, padding=3, bias=False),
            nn.GroupNorm(8, d1), nn.ReLU(inplace=True),
            nn.Conv1d(d1, d2, 5, stride=2, padding=2, bias=False),
            nn.GroupNorm(8, d2), nn.ReLU(inplace=True),
            nn.Conv1d(d2, d3, 3, stride=2, padding=1, bias=False),
            nn.GroupNorm(8, d3), nn.ReLU(inplace=True))


class CNNAttention(nn.Module):
    def __init__(self, num_classes, in_channels=1,
                 conv_dims=(16, 32, 64), d_model=64,
                 n_heads=4, n_layers=2, ff_mult=4, dropout=0.1):
        super().__init__()
        self.stem = _ConvStem(in_channels, dims=conv_dims)
        self.proj = (nn.Conv1d(conv_dims[-1], d_model, 1)
                     if conv_dims[-1] != d_model else nn.Identity())
        self.pos_enc = _SinusoidalPosEnc(d_model)
        self.cls_token = nn.Parameter(torch.zeros(1, 1, d_model))
        nn.init.trunc_normal_(self.cls_token, std=0.02)
        encoder_layer = nn.TransformerEncoderLayer(
            d_model=d_model, nhead=n_heads,
            dim_feedforward=d_model * ff_mult, dropout=dropout,
            activation="gelu", batch_first=True, norm_first=True)
        self.transformer = nn.TransformerEncoder(encoder_layer, n_layers)
        self.norm = nn.LayerNorm(d_model)
        self.classifier = nn.Linear(d_model, num_classes)

    def forward(self, x):
        feats = self.stem(x)                       # (B, C, T/8)
        feats = self.proj(feats).transpose(1, 2)   # (B, T/8, d_model)
        feats = self.pos_enc(feats)
        cls = self.cls_token.expand(feats.size(0), -1, -1)
        seq = torch.cat([cls, feats], dim=1)
        seq = self.norm(self.transformer(seq))
        return self.classifier(seq[:, 0])
\end{lstlisting}

\subsection{Training Configuration}

All three architectures in this project share the exact same training loop (\texttt{train.py}) and dataset split, so that any difference in evaluation reflects the model itself and not the training recipe.

\begin{itemize}
    \item \textbf{Dataset:} 312{,}470 windows of length 512 (199{,}988 train / 49{,}997 validation / 62{,}485 test), 7 classes, temporal split (no leakage across train/val/test).
    \item \textbf{Optimizer / loss:} Adam, learning rate $10^{-3}$, weighted cross-entropy (class weights inversely proportional to frequency).
    \item \textbf{Scheduler:} \texttt{ReduceLROnPlateau} (patience 2, factor 0.5) monitored on validation loss.
    \item \textbf{Regularization:} dropout 0.1 inside the Transformer encoder and \texttt{GroupNorm(8)} in the stem; early stopping with patience 10 and min-delta 0.005.
    \item \textbf{Batch size:} 128, max 35 epochs, sliding-window stride 32 during training.
    \item \textbf{Total parameters:} 109{,}655 trainable.
\end{itemize}

\subsection{Robustness Test}

\texttt{robustness\_test.py} sweeps two stressors independently: the standard deviation of the OU background noise and the geometric deformation of injected anomaly templates (see \texttt{data-gen}). For each multiplier, 50 events are regenerated and the model is re-evaluated event-level.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.85\textwidth]{media/cnn_attention_robustness_test.png}
    \caption{CNN+Attention robustness under increasing background noise (left) and template deformation (right).}
\end{figure}

\begin{itemize}
    \item \textbf{Noise breakdown:} Macro F1 remains at >50\% across the entire sweep up to $3.0\times$ baseline noise --- the model never breaks down within the tested range.
    \item \textbf{Deformation breakdown:} Macro F1 first drops below 50\% at multiplier \(\approx 4.9\times\) the baseline deformation variance.
\end{itemize}

The self-attention layers give the network access to global context across the entire window: even when the local shape is heavily distorted, the encoder can still classify the event based on the long-range structure of the surrounding signal. This explains the superior deformation tolerance.
