
\section{1D-CNN Implementation}
This section describes the concrete PyTorch implementation of the 1D-CNN for multi-class anomaly classification. The codebase is organized into modular scripts within the \texttt{1D-CNN/} directory, with full CUDA GPU acceleration support.

\subsection{Data Processing (\texttt{train.py})}
The data loading and preprocessing logic is embedded in the \texttt{load\_data()} function within \texttt{train.py}. It bridges the synthetic \texttt{.csv} generator and the neural network through the following steps:
\begin{enumerate}
    \item \textbf{Temporal Split:} The continuous signal is split chronologically \textit{before} windowing: the first 80\% of time steps are reserved for training and the remaining 20\% for testing. This prevents \textbf{data leakage}, which would occur with a random split because overlapping windows (stride 32 over a 512-point window) share up to 94\% of their data points.
    \item \textbf{Sliding Window Extraction:} Each split is independently sliced into overlapping windows (size 512, stride 32).
    \item \textbf{Threshold-Based Labeling:} A window is only labeled as a specific anomaly class if the anomaly occupies at least \textbf{10\%} of the window length. This prevents the CNN from learning that windows containing 99\% pure noise should be classified as anomalies. When the threshold is met, the most frequent anomaly class ID within the window is assigned via majority voting.
    \item \textbf{Per-Window Centering (Instance Normalization):} To make the network robust against the slowly wandering background baseline generated by the Ornstein-Uhlenbeck process, each sliding window is independently centered by subtracting its own local mean $\mu_{\mathrm{window}}$. However, a global standard deviation $\sigma_{\mathrm{train}}$ is computed across all centered training windows to preserve the relative amplitudes of the spikes. The test set is scaled using this same global statistic. This value is persisted to \texttt{normalization\_stats.json} for identical inference normalization:
    \begin{equation}
        x_{\mathrm{scaled}} = \frac{x - \mu_{\mathrm{window}}}{\sigma_{\mathrm{train}}}
    \end{equation}
    \item \textbf{Tensor Reshaping:} The output is reshaped into the strict \texttt{(Batch\_Size, 1, Window\_Size)} format required by PyTorch's \texttt{Conv1d} layers.
\end{enumerate}

\subsection{Architecture Definition (\texttt{model.py})}
The \texttt{Anomaly1DCNN} class inherits from \texttt{torch.nn.Module} and implements a 3-block convolutional architecture with a progressively narrowing kernel strategy:
\begin{itemize}
    \item \textbf{Block 1:} \texttt{Conv1d(in=1, out=16, kernel=7, padding=3)} $\rightarrow$ \texttt{BatchNorm1d} $\rightarrow$ \texttt{ReLU} $\rightarrow$ \texttt{MaxPool1d(2)}.
    \item \textbf{Block 2:} \texttt{Conv1d(in=16, out=32, kernel=7, padding=3)} $\rightarrow$ \texttt{BatchNorm1d} $\rightarrow$ \texttt{ReLU} $\rightarrow$ \texttt{MaxPool1d(2)}.
    \item \textbf{Block 3:} \texttt{Conv1d(in=32, out=64, kernel=5, padding=2)} $\rightarrow$ \texttt{BatchNorm1d} $\rightarrow$ \texttt{ReLU} $\rightarrow$ \texttt{MaxPool1d(2)}.
\end{itemize}
The early layers use larger kernels (7) to capture broad temporal structure such as the overall envelope of anomaly shapes, while the final layer uses a smaller kernel (5) to refine local features. The channel count doubles at each block (16 $\rightarrow$ 32 $\rightarrow$ 64), progressively expanding the network's feature representation capacity.

The network utilizes a \textbf{Regional Pooling layer} (\texttt{AdaptiveAvgPool1d(4)}) instead of Global Average Pooling. This preserves 4 distinct temporal bins, allowing the network to recognize the temporal topography of shapes---for example, distinguishing the two separate peaks of an \texttt{M} shape from a solid \texttt{bell\_sq} block, since the averaged values in each bin differ between these shapes.

This flattened vector of size 256 ($64 \times 4$) is then passed through a classifier head: \texttt{Flatten()} $\rightarrow$ \texttt{Dropout(0.4)} $\rightarrow$ \texttt{Linear(256, 32)} $\rightarrow$ \texttt{ReLU} $\rightarrow$ \texttt{Dropout(0.2)} $\rightarrow$ \texttt{Linear(32, 7)}. The total model footprint is \textbf{22,727 trainable parameters}.

\subsection{Training Loop (\texttt{train.py})}
The training script establishes the complete PyTorch training ecosystem with GPU acceleration and comprehensive logging:
\begin{itemize}
    \item \textbf{Data Split:} The training set is further divided 80/20 into train/validation subsets using a random permutation for early stopping monitoring.
    \item \textbf{Class Imbalance Handling:} Computes inverse frequency weights $w_c = \frac{N_{\mathrm{total}}}{C \cdot N_c}$ and passes them to the \texttt{CrossEntropyLoss} criterion, forcing the optimizer to treat rare anomaly shapes with the same importance as the dominant normal background.
    \item \textbf{Optimization:} Adam optimizer with initial learning rate $10^{-3}$.
    \item \textbf{Learning Rate Scheduling:} \texttt{ReduceLROnPlateau} (patience 2, factor 0.5) monitors validation loss and halves the learning rate when progress stalls.
    \item \textbf{Early Stopping:} Patience of 5 epochs. The best model weights are saved only when validation loss improves.
    \item \textbf{Logging:} A comprehensive \texttt{.txt} log and an interactive Plotly training curves chart (HTML + PNG) are generated.
\end{itemize}

\subsubsection{Training Results}
The model was trained on a 10M-point synthetic dataset (249,985 windows) on an NVIDIA GeForce RTX 5060 Laptop GPU with CUDA 12.8:
\begin{itemize}
    \item \textbf{Convergence:} 82 epochs, 9 minutes 5 seconds. Learning rate decayed from $10^{-3}$ to $8 \times 10^{-6}$ across 7 reduction steps.
    \item \textbf{Final losses:} Best validation loss = 0.2494, test loss = 0.3028.
    \item \textbf{Test accuracy:} 93.4\% per-window accuracy (62,485 windows). Event-level accuracy is significantly higher due to overlapping window accumulation during inference.
\end{itemize}

\subsection{Architecture Search}
The final architecture was selected through an empirical search over several candidate configurations. All variants were trained on the same 10M-point dataset and evaluated on both per-window test accuracy and event-level inference over a 100,000-point segment containing 77 anomaly events:

\begin{itemize}
    \item \textbf{Depth vs.\ Width:} Reducing the number of convolutional blocks below 3 degrades performance unless channel width is increased. A 2-block model with narrow channels (16$\rightarrow$32) lacked sufficient representational capacity, while a 2-block model with wider channels (32$\rightarrow$64) recovered most accuracy.
    \item \textbf{Diminishing returns of depth:} Blocks 4 and 5 contributed negligible accuracy gains while inflating the parameter count by $12\times$.
    \item \textbf{Training speed:} Tightening early stopping patience from 10 to 5 and LR scheduler patience from 4 to 2, combined with doubling the batch size to 128, reduced training time without affecting convergence.
\end{itemize}

\subsection{Inference and Evaluation (\texttt{visualize\_inference.py})}
The inference script evaluates the trained model on a continuous segment of the dataset using a fine-grained sliding window (stride 10, window 512). Two key design decisions:

\begin{enumerate}
    \item \textbf{Consistent Normalization:} The inference script loads the global $\sigma_{\mathrm{train}}$ from \texttt{normalization\_stats.json} and applies the same per-window centering strategy.
    \item \textbf{Overlapping Window Accumulation:} The softmax probability vector is \textbf{accumulated} across all points covered by each window. With stride 10 and window 512, each point is covered by up to 51 overlapping windows. The final per-point class probability is the average:
    \begin{equation}
        P_{\mathrm{final}}(c \mid t) = \frac{1}{|\mathcal{W}_t|} \sum_{w \in \mathcal{W}_t} P_w(c)
    \end{equation}
    where $\mathcal{W}_t$ is the set of all windows covering time step $t$. This ensemble-like averaging significantly reduces prediction noise.
\end{enumerate}

\subsection{Robustness Analysis (\texttt{robustness\_test.py})}
To assess the model's sensitivity to degraded signal conditions, a robustness test independently sweeps two axes while holding the other at its training baseline:
\begin{enumerate}
    \item \textbf{Background noise intensity:} The standard deviation of the high-frequency sensor noise was scaled from $1\times$ to $3\times$ the baseline value ($\sigma = 2.70$ gamma dose units).
    \item \textbf{Anomaly shape deformation:} The variance parameter of the anomaly generator was scaled from $1\times$ to $8\times$ the baseline value (0.04), controlling how much each anomaly instance deviates from its canonical template shape.
\end{enumerate}

Each configuration generated a test dataset with 50 anomaly events using a fixed random seed to ensure identical anomaly positions and template selections across all runs.

\subsection{Real-World Application (\texttt{inference\_real\_data.py})}
Beyond evaluating the model on synthetic data, the repository implements a dedicated pipeline to apply the trained 1D-CNN directly to unlabelled real-world sensor streams (e.g., \texttt{2015\_months\_DebitDoseA.txt}).

This script bridges the gap between the synthetic training environment and physical deployment:
\begin{enumerate}
    \item \textbf{Data Ingestion \& Cleaning:} It loads raw CSV sensor data, gracefully handling structural anomalies (such as malformed floating-point strings like \texttt{"97..3123"}) and interpolating missing NaN segments to maintain temporal continuity.
    \item \textbf{Overlapping Inference:} It deploys the same dense overlapping sliding-window architecture (stride 10, window 512) and ensemble-averaging technique used in synthetic evaluation to scan the continuous, unlabelled physical signal.
    \item \textbf{Diagnostic Visualization:} The script generates an interactive HTML dashboard stacking the raw physical sensor trace on top of a synchronized probability heatmap. This allows an engineer to scroll through months of raw sensor data and immediately spot points where the CNN's confidence spikes, effectively discovering anomalies in the wild that were previously hidden within the noise floor.
\end{enumerate}
