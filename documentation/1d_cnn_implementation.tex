\section{1D-CNN Implementation}

This section walks through the concrete PyTorch implementation of the baseline 1D Convolutional Neural Network used as the reference architecture for all subsequent comparisons. All paths below are relative to the \texttt{architectures/} directory.

\subsection{Architecture (\texttt{saved\_models/1d\_cnn.py})}

The network is intentionally lightweight: three Conv-BN-ReLU-MaxPool blocks with progressively widening channels (16 \(\rightarrow\) 32 \(\rightarrow\) 64) extract local shape features, followed by an \texttt{AdaptiveAvgPool1d(4)} that preserves four temporal bins (rather than collapsing to a single vector) so the classifier head can still see the rough \emph{position} of the shape inside the window. A two-layer dense head with dropout produces the class logits.

\begin{lstlisting}[language=Python]
class Anomaly1DCNN(nn.Module):
    def __init__(self, in_channels=1, num_classes=2):
        super().__init__()
        self.block1 = nn.Sequential(
            nn.Conv1d(in_channels, 16, kernel_size=7, padding=3),
            nn.BatchNorm1d(16), nn.ReLU(), nn.MaxPool1d(2))
        self.block2 = nn.Sequential(
            nn.Conv1d(16, 32, kernel_size=7, padding=3),
            nn.BatchNorm1d(32), nn.ReLU(), nn.MaxPool1d(2))
        self.block3 = nn.Sequential(
            nn.Conv1d(32, 64, kernel_size=5, padding=2),
            nn.BatchNorm1d(64), nn.ReLU(), nn.MaxPool1d(2))
        self.global_pool = nn.AdaptiveAvgPool1d(4)
        self.classifier = nn.Sequential(
            nn.Flatten(), nn.Dropout(0.4),
            nn.Linear(64 * 4, 32), nn.ReLU(),
            nn.Dropout(0.2), nn.Linear(32, num_classes))
\end{lstlisting}

\subsection{Training Configuration}

All three architectures in this project share the exact same training loop (\texttt{train.py}) and dataset split, so that any difference in evaluation reflects the model itself and not the training recipe.

\begin{itemize}
    \item \textbf{Dataset:} 312{,}470 windows of length 512 (199{,}988 train / 49{,}997 validation / 62{,}485 test), 7 classes, temporal split (no leakage across train/val/test).
    \item \textbf{Optimizer / loss:} Adam, learning rate $10^{-3}$, weighted cross-entropy (class weights inversely proportional to frequency).
    \item \textbf{Scheduler:} \texttt{ReduceLROnPlateau} (patience 2, factor 0.5) monitored on validation loss.
    \item \textbf{Regularization:} dropout (0.4 / 0.2) in the dense head; early stopping with patience 10 and min-delta 0.005 on validation loss.
    \item \textbf{Batch size:} 128, max 35 epochs, sliding-window stride 32 during training.
    \item \textbf{Total parameters:} 22{,}727 trainable.
\end{itemize}

\subsection{Training Results}

The model converged smoothly without overfitting. Training stopped at epoch 35 (no early stop) with the last \texttt{ReduceLROnPlateau} step halving the learning rate around epoch 32.

\subsection{Robustness Test}

\texttt{robustness\_test.py} sweeps two stressors independently: the standard deviation of the OU background noise and the geometric deformation of injected anomaly templates (see \texttt{data-gen}). For each multiplier, 50 events are regenerated and the model is re-evaluated event-level.

\begin{figure}[H]
    \centering
    \includegraphics[width=0.85\textwidth]{media/1d_cnn_robustness_test.png}
    \caption{1D-CNN robustness under increasing background noise (left) and template deformation (right).}
\end{figure}

\begin{itemize}
    \item \textbf{Noise breakdown:} Macro F1 first drops below 50\% at multiplier \(\approx 1.9\times\) the baseline noise standard deviation.
    \item \textbf{Deformation breakdown:} Macro F1 first drops below 50\% at multiplier \(\approx 4.9\times\) the baseline deformation variance.
\end{itemize}

The 1D-CNN is comparatively sensitive to noise: its small receptive field and lack of residual / global-context pathways mean that once high-frequency noise dominates, the local shape primitives the network relies on are washed out.
