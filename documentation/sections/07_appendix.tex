\section{Anomaly-template format}
\label{app:csv}

Each template is a CSV of keypoints with columns
\texttt{time}, \texttt{value} (both normalised to $[0,1]$),
\texttt{t\_minus}, \texttt{t\_plus}, \texttt{v\_minus}, \texttt{v\_plus}
(flags allowing jitter in each direction), and \texttt{interp}
(segment interpolation: \texttt{linear}, \texttt{exp\_up}, \texttt{exp\_down} or
\texttt{bell}). The deformation perturbs the free keypoints by a Gaussian of
std $\nu$ under these direction constraints, enforces time monotonicity, and
interpolates to a dense curve rescaled to the target amplitude and duration.

\section{Software environment}
\label{app:env}

Experiments ran on Windows~11 with Python~3.13 and PyTorch~2.12 (CUDA~12.8) on a
single NVIDIA RTX~5060 Laptop GPU, using NumPy, Pandas, Matplotlib, SciPy and
scikit-learn for data handling, metrics and figures. The repository contains the
generator (\texttt{data-gen/}), the models and training/evaluation scripts
(\texttt{architectures/}), and this report with a figure-rebuild script
(\texttt{documentation/}).
